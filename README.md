# 🌦️ Weather Application

This is a simple weather application that I built as a project to practice web development.

The app allows users to search for a city and see its current weather information. It also has a "Use My Location" option to get weather information based on the user's current location.

## What the app can do

- Search for the weather of any city
- Show the current temperature
- Show the "feels like" temperature
- Show humidity
- Show wind speed
- Show atmospheric pressure
- Show visibility
- Get weather using the user's location
- Show an error message when a city is not found
- Work on both desktop and mobile screens

## Technologies I used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenWeatherMap API
- Bootstrap

## How I built it

The frontend is made using HTML, CSS and JavaScript.  
The backend is built using Node.js and Express.js.
The application gets weather data from the OpenWeatherMap API and displays the information in a simple and responsive interface.

## How to run the project

First, download or clone this repository and open it in VS Code.
Go inside the `backend` folder and install the required packages:

```bash
npm install
```
